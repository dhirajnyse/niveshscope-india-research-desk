# Pilot Demo Room

The Pilot Demo Room is the founder-facing demo layer for NiveshScope. It turns the large research desk into a clear five-minute walkthrough with a sample question launcher, source-safety language, follow-up copy, and an exportable demo pack.

## What It Produces

- A readiness score for whether the current build is suitable for a pilot demo.
- A five-minute talk track that starts with the Indian equity research pain, shows the desk, explains evidence controls, and closes with a practical pilot ask.
- Three sample questions that demonstrate single-company risk work, comparative analysis, and forward-looking operating questions.
- Source-safety wording that makes it clear when SYN starter evidence is still present and what must become REAL before investment use.
- A JSON demo pack and copyable follow-up note for founder-led pilot conversations.

## Operator Workflow

1. Open Pilot Demo Room from the hero navigation, top Demo button, quick navigator, or command palette.
2. Review the demo score and caveats before sharing the screen.
3. Click `Load demo question` to run the RELIANCE risk example in the desk.
4. Point out selected-ticker guard, evidence quality, real-source completeness, and the right-rail source checklist.
5. Copy the demo script or follow-up note after the conversation.
6. Export the demo pack if the pilot needs a repeatable handoff record.

## Why It Exists

The product has become broad enough that a new user can feel lost. The demo room keeps the story simple: ask a real research question, inspect the cited answer, show the safety gates, then agree on the first real source collection pilot. It also keeps synthetic starter evidence from being accidentally presented as production-ready research.

## Production Direction

The static room is a browser-side demo helper. A production version should connect each demo to authenticated accounts, named pilot users, CRM notes, demo outcome tracking, source replacement commitments, and follow-up automation. It should also record whether the user saw the SYN evidence disclosure and which sample question created the strongest buying signal.
