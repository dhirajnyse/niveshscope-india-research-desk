# Guided Product Tour

The Guided Product Tour is the v51 onboarding layer for NiveshScope. The desk now has many rooms, actions, and quality gates, so the tour gives a new operator a simple path through the product before they start clicking around.

## Tour Path

1. Start with a focused question in the Research Desk.
2. Replace SYN evidence with REAL annual report, concall, results, shareholding, or announcement sources.
3. Paste, extract, and review source text in Source Studio.
4. Check investment readiness and answer quality.
5. Package the research output through IC Memo, PDF, Markdown, and saved briefs.
6. Move quickly with Find, Ctrl+K/Cmd+K, and the floating Nav drawer.

## Behavior

- The top-right `Tour` button opens the walkthrough.
- The hero `Start tour` action opens the same tour for first-time users.
- Each step can jump to the relevant workspace room.
- Next, Back, and step buttons let the operator move at their own pace.
- Closing the tour records that it has been seen in local browser storage.

## Product Role

This feature is designed to reduce confusion, not to add more research logic. It teaches the mental model of the product: ask, source, verify, package, and navigate. That path is the beginner-friendly version of the future analyst workflow.

## Production Direction

In production, the tour should become account-aware. New users can get the tour automatically once, while returning users can restart it from Help. Later versions can add role-specific tours for analysts, reviewers, and administrators.
